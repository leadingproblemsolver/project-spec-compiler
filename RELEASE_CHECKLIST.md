# Release checklist

- [ ] Tests pass from a clean checkout.
- [ ] Console entry point executes.
- [ ] Primary smoke workflow succeeds.
- [ ] Build produces a versioned wheel.
- [ ] README commands match the CLI.
- [ ] CI repeats tests and the primary validation command.
- [ ] Container definition matches the package entry point.
- [ ] No credentials, caches, generated build directories, or private data are committed.
- [ ] AI–human provenance is explicit.
- [ ] Human ownership sprints identify remaining competence proof.
- [ ] Deployment limitations are stated.
- [ ] Distribution/activation claims do not exceed observed evidence.
