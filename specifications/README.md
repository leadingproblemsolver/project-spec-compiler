# Project YAML Specifications

This package contains canonical, segmented engineering specifications for:

- `cgebs-execution-kernel`
- `signalops-workbench`

Use the numbered YAML files for targeted review and `project.bundle.yaml` for complete
machine-readable context. `00_portfolio_registry.yaml` defines how the projects relate.
`01_framework_application_contract.yaml` is the reusable contract for applying the same
structure to another project.

The files deliberately distinguish implemented behavior from planned or deferred work.
